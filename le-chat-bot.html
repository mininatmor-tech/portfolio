Le Chat

Bot Discord complet et modulaire pour la gestion communautaire

Node.js discord.js v14 MySQL

À propos du projet

Le Chat est un bot Discord complet développé en JavaScript (Node.js, discord.js v14), conçu pour offrir une solution de gestion et de modération complète pour les serveurs Discord. Avec une architecture modulaire basée sur des modules dédiés à chaque fonctionnalité et une base de données MySQL, il permet d'ajouter facilement de nouvelles fonctionnalités tout en gardant un code organisé.

Fonctionnalités principales

Modération avancée

Commandes de modération complètes pour maintenir l'ordre sur le serveur :

  • Kick, ban et unban
  • Mute / unmute temporisé
  • Système d'avertissements (warn, warns, clearwarns)
  • Suppression en masse de messages (clear)

Automodération

Filtrage automatique des messages en temps réel :

  • Détection de mots interdits
  • Blocage des liens d'invitation Discord
  • Détection de spam (seuil de messages sur une fenêtre de temps)
  • Suppression automatique et sanction

Système de logs complets

Suivi détaillé de toute l'activité du serveur via des embeds :

  • Arrivées et départs de membres
  • Messages supprimés et modifiés
  • Actions de modération
  • Événements du serveur

Rôles & bienvenue

Gestion des rôles et accueil des nouveaux membres :

  • Menus de rôles par réaction, personnalisables (titre, description, image)
  • Ajout d'options de rôle avec emoji et libellé
  • Bannières de bienvenue et d'au revoir générées automatiquement

Niveaux & activité vocale

Un système de progression pour récompenser l'activité :

  • XP et niveaux par message (voir, classement, ajouter, définir, reset)
  • Suivi du temps passé en vocal, avec classement

Tickets & abonnements

Des outils pratiques pour la communauté :

  • Panneau de tickets avec ouverture/fermeture par bouton
  • Suivi d'abonnements personnels (Netflix, Spotify, etc.) avec cycle de renouvellement
  • Rappels automatiques avant échéance
  • Rappels de bump Disboard automatisés

Architecture technique

Le bot est organisé en modules indépendants (un par fonctionnalité : modération, automod, logs, rôles, niveaux, vocal, tickets, abonnements, bump), chargés depuis un point d'entrée central. Cette approche offre plusieurs avantages :

  • Code organisé et facile à naviguer
  • Modules isolés et faciles à faire évoluer indépendamment
  • Déploiement et maintenance simplifiés
  • Extensibilité sans limite

Les données persistantes (niveaux, vocal, abonnements, configuration des rôles) sont stockées dans une base de données MySQL.

Technologies utilisées

  • Node.js : Environnement d'exécution JavaScript
  • discord.js v14 : Bibliothèque pour l'intégration Discord
  • MySQL : Stockage des données persistantes

Apprentissages clés

Ce projet m'a permis de développer mes compétences en :

  • Architecture de projets Node.js complexes et modulaires
  • Gestion de bases de données MySQL
  • Intégration d'APIs (Discord API) et de webhooks
  • Modération automatisée et gestion d'erreurs
  • Conception de systèmes de progression (XP, niveaux, classements)
