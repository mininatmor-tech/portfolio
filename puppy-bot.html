Puppy

Bot Discord complet en JavaScript : économie, roleplay et outils de gestion de serveur

Node.js JavaScript (ES Modules) discord.js v14 MySQL

À propos du projet

Puppy est un bot Discord écrit en JavaScript moderne (Node.js, ES Modules) avec la bibliothèque discord.js v14. Toutes ses commandes fonctionnent à la fois en préfixe classique (p/) et en Slash (/), aussi bien sur serveur qu'en messages privés. Il combine un système d'économie complet, des commandes de roleplay interactives et des outils utilitaires pour les administrateurs de serveur.

Fonctionnalités principales

Économie

Un système économique complet avec portefeuille et compte en banque :

  • Prime quotidienne et travail rémunéré
  • Dépôt / retrait bancaire
  • Boutique, achat et vente de ressources
  • Pêche et minage (avec cooldowns)
  • Cambriolage entre joueurs
  • Inventaire détaillé

Roleplay interactif

Des commandes sociales avec boutons de réponse :

  • hug, pat, kiss, slap, cuddle
  • Bouton "Rendre l'action" exclusif à la cible
  • sleep avec réponse interactive ("Dormir ensemble")
  • Actions solo comme cry

Outils utilitaires

Des commandes pour la gestion et l'information du serveur :

  • help contextuel par commande
  • ping (latence bot / passerelle)
  • serverinfo et userinfo
  • setwelcome pour le message de bienvenue

Double interface de commandes

Une abstraction unifiée pour préfixe et slash :

  • Support préfixe (p/) et Slash (/)
  • Fonctionne en serveur et en MP
  • Contexte de commande unifié (CommandContext)

Persistance des données

Une couche de base de données robuste :

  • Base de données MySQL en production
  • Fallback automatique sur database.json
  • Migration transparente entre les deux

Architecture modulaire

Un code organisé et facile à faire évoluer :

  • Commandes séparées par catégorie
  • Événements Discord isolés (ready, messageCreate, interactionCreate)
  • Déploiement des Slash commands via script dédié

Architecture technique

Puppy est organisé en modules clairs : commands/ (économie, roleplay, utilitaires), events/ (cycle de vie du bot et gestion des interactions), et utils/ (contexte de commande unifié, appels API pour les gifs animés, formatage des durées).

  • Chargement dynamique des commandes et événements
  • Synchronisation des Slash commands via l'API REST de Discord
  • Configuration centralisée (boutique, jobs, ressources) dans constants.js
  • Bascule automatique MySQL / JSON selon la disponibilité de la base

Technologies utilisées

  • Node.js : Environnement d'exécution JavaScript
  • discord.js v14 : Bibliothèque pour l'intégration Discord
  • MySQL : Base de données pour la persistance des données
  • JSON : Stockage de secours et configuration

Apprentissages clés

Ce projet m'a permis de développer mes compétences en :

  • Développement d'un bot Discord multi-interfaces (préfixe et Slash)
  • Conception d'un système économique avec cooldowns et persistance
  • Intégration d'une base de données MySQL avec repli automatique
  • Gestion d'interactions Discord (boutons, réponses différées)
  • Organisation d'un projet Node.js modulaire et maintenable
